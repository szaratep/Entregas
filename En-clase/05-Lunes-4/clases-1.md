# Ejercicios en Clase
1. Personas
   - Crear un algoritmo que capture los datos personales de 5 individuos, estos deberan ser: nombre, edad, genero. 
   - Una ves esten capturados en una lista, vamos a contar cuantos son hombres y cuantos son mujeres. 
   - Si has logrado realizar los puntos anteriores, vas a modificar el algoritmo de manera que preguntes ¿Cuántas personas deseas registrar? 

**NOTA:** Este ejercicio debe realizarse usando clases.

2. Crea una clase que represente un Carro, asegurandose que las propiedades que necesitas sean consistentes, permitiendo que el automovil, pueda:
   - Acelerar: Cada que se invoque este metodo el automovil debe acelerar 1km. Sin embargo, este metodo recibe un valor, por ejemplo: 10, el debe incrementar 10km/h.
   - Frenar: Cada que se invoque este metodo el automovil debe frenar 1km. Sin embargo, este metodo recibe un valor, por ejemplo: 10, el debe rebajar su velocidad a 10km/h.
  
**NOTA:** Es importante recordar que todo sistema tiene requerimientos implicitos que debemos tener en cuenta, para que nuestro algoritmo funcione correctamente, por ejemplo: No podemos frenar y reducir la velocidad mas allá de los 0km/h, no es el único requerimiento implicito, ponte a prueba y desarrolla una clase que opere correctamente.
